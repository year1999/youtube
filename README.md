# ⚡ Embedded & Electronics projects

Welcome to my personal hardware and electronics repository! Here you will find code, wiring diagrams, and documentation for various projects built using microcontrollers, single-board computers, and custom circuits.

## 🛠️ Tech Stack & Hardware
* **Microcontrollers:** Arduino (Uno, Nano, ESP32, ESP8266)
* **Single-Board Computers:** Raspberry Pi (Pi 4, Zero, Pico)
* **Languages:** C++, Python, MicroPython
* **Sensors & Actuators:** I2C/SPI modules, motors, displays, and IoT sensors

## 📁 Repository Structure
```text
├── arduino/          # Arduino sketches (.ino) and libraries
├── raspberry-pi/     # Python scripts and configuration files for Raspberry Pi
├── picos/            # Raspberry Pi Pico (CircuitPython/MicroPython/C++)
├── schematics/       # Fritzing diagrams, wiring diagrams, or CAD files
└── docs/             # Project notes, pinouts, and component datasheets
